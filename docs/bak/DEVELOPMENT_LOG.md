- **影响范围**：供应商发货创建的国内段物流追踪；不影响发货事务本身，但会缺少物流状态、轨迹和签收事实。

- **选择原因**：受限启动避免误触发其他生产任务；非强制幂等注册可跳过已成功、在途或签收记录；先单号后批量可控制外部服务和生产写入风险。
- **契约变化**：无代码或数据库结构变化；仅产生正常的服务商注册尝试、载荷和轨迹事件。

- **当前状态**：生产数据补偿完成；XXL-JOB 受限进程在本次会话结束时仍运行。

### 2026-08-14：WMS 签收后未提醒运营配置 FBA 货件号

- **现象**：WMS 发货管理完成签收并产生库存后，对应运营没有收到钉钉提醒，库存调度记录因此可能长期缺少 FBA 货件号，无法进入 FBA 发货。

- **方案原因**：钉钉账号映射、发送日志和失败重试属于 ERP，WMS 只负责签收事实，避免在 WMS 复制凭据和消息基础设施。
- **验证证据**：WMS 专项测试验证成功签收后仅通知一次且状态更新为已签收；ERP 专项测试验证接收人为对应运营、通知类型和 FBA 配置链接。
- **剩余风险**：部署时必须在两端配置相同内部 Token 和正确 ERP 内部接口地址；历史已签收记录不会由本次实时通知自动补发。
- **选择原因**：生产由 XXL-JOB 管理调度频率和告警，注册状态机仍保持单一实现，不新增表或重复第三方协议代码。
- **验证证据**：补偿服务单元测试覆盖请求字段映射和单条失败隔离；Handler 测试覆盖默认参数、自定义参数和安全边界；XXL executor 模块编译与测试结果见本次交付记录。
- **剩余风险**：候选 SQL 依赖共享表字段与索引；生产首次启用应使用单机串行、小批量观察第三方限流及雪花 ID 时钟回拨告警。
