# ModernWMS 登录页重构设计

## 目标

以用户提供的登录页截图为视觉基准，重构现有桌面端登录页，使品牌、仓储物流主视觉和登录操作形成清晰的左右分区。保留现有账号密码登录、密码显隐、记住密码、表单校验和登录跳转逻辑，不新增 SSO、注册或其他认证方式。

## 视觉方向

- 页面采用浅蓝白色背景、深蓝标题和亮蓝交互色，延续参考图的专业物流系统风格。
- 顶部设置独立品牌栏，使用项目现有 `logo.png`，配合“南阳有座山”和“物流管理系统”文字。
- 主体左侧展示系统标题、价值短语和用户提供的 `nyamtn.png` 仓储物流插画。
- 左侧底部展示库存管理、运输管理、订单管理、数据统计四项能力，用项目已安装的 Material Design Icons 表达，不制作自定义图标。
- 主体右侧为白色登录卡片，包含欢迎标题、系统副标题、用户名、密码、记住密码和蓝色登录按钮。
- 不显示“其他登录方式”、SSO 图标或 SSO 文案。
- 页脚保留现有版权和备案入口，但调整为参考图中的居中弱化样式。

## 页面结构

`login.vue` 负责整页布局，分为：

1. 品牌栏：现有 Logo 与品牌文字。
2. 主内容区：左侧品牌主视觉和右侧登录卡片。
3. 左侧能力栏：四个业务能力说明。
4. 页脚：版权与备案信息。

`login-form.vue` 继续负责登录表单和全部认证行为，只重构表单标记和样式，不改变接口调用、Pinia 状态写入、权限加载或路由跳转。

## 响应式规则

- 宽屏：左右两栏，左侧约 64%，右侧约 36%，登录卡片保持合适的最大宽度。
- 中等屏幕：压缩左侧标题、插画和能力栏间距，登录卡片仍完整可用。
- 窄屏和手机：隐藏非必要的左侧主视觉与能力栏，保留紧凑品牌栏、登录卡片和页脚，避免横向滚动。
- 页面高度不足时允许主体纵向滚动，避免表单或页脚遮挡。

## 资源

- 品牌图标：复用 `frontend/src/assets/img/logo.png`。
- 左侧主图：从 `D:\Users\Administrator\Desktop\nyamtn.png` 复制到前端资源目录，并由 Vite 打包。
- 表单和能力图标：复用 Vuetify 已支持的 Material Design Icons。

## 行为与数据流

1. 用户填写用户名和密码，可切换密码显隐和记住密码。
2. 点击登录或按回车触发现有表单校验。
3. 校验通过后调用现有登录接口，保存令牌和用户信息，加载权限并跳转首页。
4. 接口或权限失败时继续使用现有消息组件提示。
5. 备案号继续打开工信部备案网站。

## 验收标准

- 页面整体结构、色彩、间距和层级与参考图方向一致。
- 品牌图标使用项目现有资源，左侧主图使用 `nyamtn.png`。
- 页面中不存在 SSO 入口或相关占位区域。
- 原有登录、回车提交、密码显隐、记住密码、错误提示和成功跳转行为不变。
- 桌面与手机视口均无溢出、遮挡或不可点击控件。
- TypeScript/Vue 构建通过，浏览器控制台无新增错误，并完成同视口截图对照检查。
